## API 429 配额耗尽

若日志出现：

```
HTTP 429  "Your token-plan quota has been exhausted."
```

表示 Token Plan **Credits 用完**，不是代码或 URL 错误。

- 查看额度：[Token Plan 控制台](https://bailian.console.aliyun.com/?tab=plan#/efm/subscription/token-plan) / [费用中心](https://billing-cost.console.aliyun.com/token-plan/summary)
- 停止空转：`kill $(cat .../logs/qa_pipeline.pid)`
- 恢复后降并发：`DF_MAX_WORKERS=5 nohup.sh`
- Pipeline **不支持断点续跑**，重启会从头覆盖 step 缓存

协议说明：使用 **OpenAI 兼容** `.../compatible-mode/v1/chat/completions`，**不是** Anthropic 端点。
